# Sprint_7: Тестирование API Яндекс Самокат
## Проект автоматизированного тестирования API учебного сервиса Яндекс Самокат.

Проект содержит комплексные тесты для REST API сервиса Яндекс Самокат, покрывающие основные функциональности:

- Создание и управление курьерами
- Авторизация в системе
- Создание заказа
- Получение информации о заказах

### Установка зависимостей
```
pip install -r requirements.txt
```

### Запуск тестов
```
# Запуск всех тестов
pytest

# Запуск с генерацией Allure отчета
pytest --alluredir=allure-results

# Запуск конкретного тестового модуля
pytest tests/test_courier.py -v

# Просмотр отчета
allure serve allure-results
```
